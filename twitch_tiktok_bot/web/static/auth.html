Setup checklist

  1. Create an app at TikTok for Developers.
  2. Add Login Kit (Desktop) and Content Posting API. Request scopes: user.info.basic, video.upload, video.publish.
  3. Register redirect URI exactly: http://127.0.0.1:8766/callback/
  4. Paste Client key + Client secret into the fields below, then Connect TikTok.
  5. Use a Sandbox first if Content Posting isn’t approved yet. Export packs still work without API approval.

Loading…

Setup checklist

  1. Create a Meta app at developers.facebook.com/apps.
  2. Add Instagram → API setup with Instagram login (Professional / Business account required).
  3. Add OAuth redirect URI exactly: http://127.0.0.1:8765/callback/
  4. Request scopes instagram_business_basic and instagram_business_content_publish.
  5. Paste App ID + App Secret below, then Connect Instagram.
  6. Until Meta approves advanced access, only app roles / testers can connect. Export packs still work without API.
